# package.json Notes

## name

The name of the Node.js project or package.

## version

The current version of the project. It follows semantic versioning (major.minor.patch).

## description

A short summary explaining the purpose of the project.

## main

The entry point (main JavaScript file) of the application.

## scripts

Contains commands that can be run using npm, such as `npm start` or `npm test`.

## keywords

A list of keywords that describe the project and help users find it.

## author

The name of the person or organization that created the project.

## license

Specifies how others are allowed to use, modify, and distribute the project.

## package.json vs package-lock.json

### package.json

- Stores information about the project such as its name, version, scripts, dependencies, and devDependencies.
- Specifies which packages the project requires.

### package-lock.json

- Automatically generated by npm.
- Records the exact versions of every installed package and its dependencies.
- Ensures everyone working on the project installs the same versions, resulting in consistent builds across different machines.

### Difference

`package.json` describes the project's dependencies and configuration, while `package-lock.json` locks the exact dependency versions used during installation.
